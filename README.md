# 로컬 북-틱 팩토리 (Local Book-Tik Factory)

지역 공공도서관을 위한 **AI 기반 숏폼 북트레일러 자동 생성 서비스**.
전국 베스트셀러가 아닌 **우리 동네 실제 대출·소장 데이터**를 분석해, 1분 분량의
세로형 MP4 영상을 자동으로 만들고 QR 코드로 소장 도서관까지 안내한다.

## 데이터 매시업 (3종)

- **도서관 정보나루 Open API** — 지역·연령별 대출/소장 데이터, 회전율 산출
- **솔로몬(사서 의사결정지원)** — 사서가 추출한 장서 분석 CSV (선택적 보강)
- **국가서지 LOD (SPARQL)** — 국립중앙도서관 온톨로지 기반 서지정보
