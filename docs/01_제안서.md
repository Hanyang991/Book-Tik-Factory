## 1. 기획 배경 및 문제 정의

### 1-1. 현황 및 문제 인식

현재 공공도서관은 MZ·알파세대의 미디어 소비 문법과 점점 멀어지고 있습니다.

- **콘텐츠 소비 방식의 변화:** MZ·알파세대는 텍스트 중심의 도서 소개보다 숏폼 영상(유튜브 쇼츠, 인스타그램 릴스, TikTok)을 통해 정보를 소비합니다.
- **사서의 SNS 홍보 역량 한계:** 도서관 SNS 홍보 영상 제작은 전문 편집 역량과 많은 시간을 요구하며, 대부분의 도서관에서는 체계적인 디지털 마케팅이 이루어지지 못하고 있습니다.
- **기존 상업 서비스의 한계:** 시중 AI 도서 소개 영상 서비스는 전국 베스트셀러 또는 대형 출판사의 광고 도서에만 집중되어 '지역 도서관 장서'와의 연계성이 없습니다.

### 1-2. 해결 방향

공공데이터인 **도서관 정보나루**, **솔로몬**, **국가서지 LOD**를 결합하고, AI 기술로 자동화함으로써 전국 어느 도서관 사서든 클릭 몇 번만으로 우리 동네 맞춤형 숏폼 북트레일러를 즉시 생성·배포할 수 있는 솔루션을 제안합니다.

## 3. 필수 활용 데이터 및 매시업 구조

공모 요강에 제시된 핵심 데이터 3종을 유기적으로 결합하여 영상 제작의 타당성과 효율성을 극대화합니다.

### 3-1. 도서관 정보나루 (Open API) — 주 데이터 소스

- **활용 데이터:** 지역별·연령별 대출 현황, 도서관별 소장·대출 건수, **대출 급상승(전주 대비) 데이터**
- **활용 방법:** 지역(시·군·구 행정구역 코드) 단위로 "서울시 서초구 20대가 이번 주 가장 많이 빌린 소설 Top 5"와 같이 **초지역화된 숏폼 제작 대상 도서 풀(Pool)** 을 구성합니다(이용자 GPS는 최종 QR 랜딩의 '가까운 도서관 안내'에서 활용). 또한 도서관별 소장 수 대비 대출 건수로 **장서 회전율을 직접 산출**하여 타깃 도서를 선정하고, **대출 급상승폭으로 '지금 뜨는 화제 도서'를 포착**합니다.
- **차별점:** 전국 베스트셀러가 아닌, 우리 동네 실제 대출 데이터 기반의 큐레이션은 **오직 도서관 공공데이터로만 구현 가능한 독점적 가치**입니다.

### 3-2. 사서의사결정지원서비스 솔로몬 (Solomon) — 보완 인사이트

- **활용 방식:** 솔로몬은 사서 회원 기반의 웹 분석 서비스로, 프로그래밍 방식의 직접 API 호출보다는 **사서가 솔로몬에서 내보낸 장서 분석 CSV 리포트를 본 솔루션에 입력**하는 방식으로 연계합니다.
- **활용 데이터:** 솔로몬의 장서 분석 리포트(장서 회전율, 유사 도서관 비교 데이터)를 업로드하면, 정보나루 대출 데이터와 교차 분석하여 숏폼 제작 우선순위를 정교화합니다.
  - **타입 A — 숨은 명저 발굴:** 솔로몬 장서 평가는 높으나 실제 대출이 저조한 도서 → 숏폼으로 노출 확대
  - **타입 B — 회전율 개선 대상:** 보유 장서 수 대비 대출 건수가 낮은 도서 → 집중 홍보로 장서 운영 효율 제고
- **기여 효과:** 단순 인기 도서 홍보를 넘어, **도서관 장서 운영의 실질적 효율화**에 기여합니다.

### 3-2-1. 쇼츠·SNS 화제 도서 (타입 C) — 트렌드 연계

- **배경:** 유튜브 쇼츠·인스타 릴스·북톡(BookTok)에서 화제가 된 책은 MZ·알파세대의 관심도가 이미 높아, 도서관 장서와 연결만 되면 즉각적인 대출 전환이 기대됩니다.
- **타입 C — 쇼츠/SNS 화제 도서:** 지금 온라인에서 회자되는 책을 제작 대상에 포함하고, **"이 화제의 책, 우리 동네 어느 도서관에 있는지"** 를 QR/위치로 바로 안내합니다.
- **화제성 신호(무료·현실적 설계):**
  - 정보나루 **대출 급상승**(전주 대비 상승폭)을 트렌드 프록시로 활용 → 별도 SNS 계정/API 없이도 '뜨는 책' 포착
  - 사서가 입력하는 **트렌드 큐레이션 리스트(CSV/키워드)** → 북튜브·북톡 화제작을 사람이 직접 반영
  - (정식 서비스) SNS 트렌드 분석 API 연동은 업그레이드 경로로 명시
- **차별점:** 화제는 SNS에서 소비되지만 **실제 대출은 동네 도서관에서 일어나도록** 온라인 관심을 오프라인 방문으로 전환합니다.

### 3-3. 국가서지 링크드오픈데이터 (LOD) — 대본 원천 소스

- **활용 데이터:** 표준 서지정보(ISBN, 저자, 출판사), 주제 분류, 도서 유형 정보
- **활용 방법:** 국립중앙도서관 자체 온톨로지(NLK Ontology) 기반 SPARQL 쿼리로 해당 ISBN의 서지 데이터를 조회하여 AI 대본 생성의 기초 소스로 활용합니다. LOD는 공공저작물로 저작권 제약 없이 자유롭게 이용 가능합니다.
- **입력 보완:** LOD에서 제공되지 않는 줄거리 정보는 사서가 직접 한 줄 요약을 입력하거나, 알라딘·교보 등 공개 도서 소개 페이지를 참고 소스로 활용합니다.

### 3-4. 데이터 매시업 흐름도

```
[정보나루] 지역별 대출 데이터 + 소장/대출 건수
        +
[솔로몬]  사서가 내보낸 장서 분석 CSV (선택적 업로드)
        │
        ▼
   교차 분석 → 이번 주 제작 대상 ISBN 선정 (숨은 명저 / 회전율 개선 / 쇼츠·SNS 화제 도서)
        ▲
   [정보나루 대출 급상승] + [사서 트렌드 큐레이션 CSV] → 화제성 신호
        │
        ▼
[국가서지 LOD] NLK 온톨로지 SPARQL → 서지 정보(저자·주제분류) 조회
        │
        ▼
[AI 처리] 스크립트 생성 → TTS → 영상 렌더링
        │
        ▼
[최종 산출물] 지역 맞춤형 숏폼 MP4 + 도서관 위치 정보 QR 연동
```

## 4. 저작권 리스크 최소화 및 상생 전략

### 4-1. 법적 리스크 최소화 설계

- **공공저작물 우선 활용:** 대본 작성의 원천 소스를 공공저작물인 국가서지 LOD로 한정하여 저작권 분쟁 소지를 차단합니다.
- **AI 재창작 프로세스 도입:** 도서 본문 또는 줄거리를 직접 인용하지 않고, LLM이 핵심 키워드와 주제 분류 정보만을 기반으로 완전히 새로운 스토리텔링 스크립트를 생성(Abstractive Summarization)합니다. 이를 통해 복제권 및 공중송신권 침해 리스크를 최소화합니다.

### 4-2. 출판사·저작권자와의 상생 로드맵 (장기)

서비스 운영을 통해 숏폼 마케팅이 실제 도서 대출 및 인지도 향상으로 이어지는 효과 데이터를 축적한 후, 출판사 및 저작권자와의 정식 협약 체계를 단계적으로 구축합니다.

| 단계 | 내용 |
|------|------|
| **1단계** | 공공저작물 기반 운영, 효과 데이터 축적 |
| **2단계** | 효과 데이터를 근거로 출판사 협약 제안 (무료 홍보 채널 제공) |
| **3단계** | 출판사 제공 공식 줄거리 소스 확보 → 콘텐츠 품질 고도화 |

> 출판사에게는 **무료 홍보 채널**을, 도서관에게는 **안전한 마케팅 소스**를 제공하는 상생 모델로 발전시킵니다.

## 5. 활용 AI 기술 및 솔루션 작동 프로세스

### 5-1. 활용 AI 기술 목록

#### PoC / 프로토타입 단계 (무료 스택)

| AI 기술 | 활용 도구 | 역할 |
|---------|----------|------|
| **텍스트 생성 AI (LLM)** | Gemini 2.5 Flash (Google AI Studio) | LOD 서지 데이터 기반 숏폼 전용 후킹 스크립트 자동 생성 |
| **음성 합성 AI (TTS)** | Edge TTS (Microsoft, 무료) | 장르별 분위기에 맞는 한국어 AI 음성 자동 생성 |
| **영상 편집 자동화** | FFmpeg (오픈소스) | 이미지 + 오디오 + 자막 합성 → MP4 자동 렌더링 |
| **배경 이미지** | Pexels API (무료 스톡) | 장르별 저작권 무료 배경 이미지 자동 조회 |

#### 정식 서비스 단계 (품질 고도화)

| AI 기술 | 활용 도구 | 역할 |
|---------|----------|------|
| **텍스트 생성 AI (LLM)** | Claude / GPT-4o | 스크립트 품질 고도화 |
| **음성 합성 AI (TTS)** | Typecast / Clova Voice | 유료 전문 AI 성우 음성 |
| **이미지 생성 AI** | Stable Diffusion / DALL·E | 도서 분위기 맞춤 일러스트 자동 생성 |

### 5-2. 솔루션 작동 프로세스 (4단계 자동화)

**1단계 | 데이터 수집 및 타깃 선정**
- 도서관 정보나루의 지역별 대출 데이터 및 소장·대출 건수를 자동 수집하여 장서 회전율 산출, 대출 급상승폭으로 화제성 신호 포착
- 솔로몬 CSV 리포트(선택)·사서 트렌드 큐레이션과 교차 분석하여 이번 주 숏폼 제작 대상 ISBN 자동 선정 (숨은 명저 / 회전율 개선 / 쇼츠·SNS 화제 도서)

**2단계 | AI 스크립트 생성**
- 국가서지 LOD(NLK 온톨로지)에서 해당 ISBN의 서지정보, 주제 분류 데이터를 조회
- Gemini 2.5 Flash가 결말을 노출하지 않고 절정까지만 묘사하는 **1분 분량의 숏폼 전용 후킹 대본** 자동 생성
  > 예시: *"만약 내일 당장 당신 통장에 100억이 꽂혔는데, 그 돈의 출처를 절대 말하면 안 된다면? — 이 소설 속 주인공이 딱 그 상황입니다."*

**3단계 | 영상 자동 렌더링**
- Edge TTS로 장르별 맞춤 AI 음성 생성 (스릴러 → 긴박감, 로맨스 → 따뜻함)
- Pexels API로 장르 키워드 기반 세로형(9:16) 배경 이미지 자동 수집
- FFmpeg으로 오디오 + 이미지 + 동적 자막을 합성하여 최종 **MP4 파일 자동 빌드**

**4단계 | 배포 및 오프라인 Action 유도**
- 생성된 영상 마지막 화면에 **QR코드 삽입** (숨은 명저·화제 도서 등 모든 타입 공통)
  - 시청자 스캔 시: 현재 위치 기반 가장 가까운 대출 가능 도서관 정보 + 잔여 장서 수 안내 페이지로 연결
  - 특히 화제 도서는 "쇼츠에서 본 그 책, 가장 가까운 ○○도서관에 대출 가능"으로 온라인 관심을 즉시 방문으로 전환
- 사서는 완성된 MP4를 즉시 다운로드해 도서관 공식 인스타그램·유튜브에 업로드 (향후 SNS 업로드 API 연동 시 원클릭 자동 게시로 확장)

## 6. 기대 효과

### 6-1. 도서관 운영 측면

- **사서 업무 경감:** ISBN 입력만으로 고퀄리티 숏폼 영상이 자동 생성되어 SNS 홍보 부담 대폭 감소
- **장서 운영 효율화:** 정보나루·솔로몬 데이터 연계로 대출이 저조한 우수 장서를 선별 홍보하여 장서 회전율 개선
- **지역 도서관 브랜딩:** 우리 동네 맞춤형 콘텐츠로 지역 주민과의 접점 강화

### 6-2. 이용자 측면

- **독서 진입장벽 완화:** 숏폼이라는 익숙한 미디어 포맷으로 독서에 대한 심리적 장벽 낮춤
- **초지역화 큐레이션:** "우리 동네 또래들이 지금 읽는 책"이라는 공감 요소로 대출 동기 유발
- **화제성 연결:** 쇼츠·SNS에서 본 화제 도서를 "우리 동네 도서관"에서 바로 찾도록 온라인 관심을 오프라인 대출로 전환
- **오프라인 연결:** QR코드를 통한 즉각적인 도서관 방문 유도

### 6-3. 공공데이터 생태계 측면

- **정적 데이터의 엔터테인먼트화:** 정적 데이터로만 존재하던 도서관 공공데이터를 가장 파급력 높은 뉴미디어 콘텐츠로 재탄생
- **데이터 활용 모델 제시:** 3종 도서관 데이터의 유기적 매시업 사례를 통해 공공데이터 융합 활용의 새로운 표준 제시
