## 1. 스페이싱 토큰

**기본 단위: 8px 그리드** 기반으로 모든 여백과 간격을 설계합니다.
Figma Local Variables에 아래 토큰을 등록해 주세요.

| Token | Value | 주요 사용처 |
|---|---|---|
| `space-1` | 4px | 아이콘 ↔ 인라인 텍스트 간격, 배지 내부 상하 패딩 |
| `space-2` | 8px | 배지 내부 좌우 패딩, 소형 컴포넌트 내부 간격 |
| `space-3` | 12px | 버튼 상하 패딩, 툴팁 내부 패딩 |
| `space-4` | 16px | 버튼 좌우 패딩, 컴포넌트 간 gap, 인풋 내부 좌우 패딩 |
| `space-5` | 24px | 카드 내부 전체 패딩, 인풋 그룹 간 gap |
| `space-6` | 32px | 섹션 내 주요 요소 간 마진 |
| `space-7` | 48px | 섹션 간 마진, 헤더 하단 여백 |
| `space-8` | 64px | 페이지 최상단/하단 패딩 |

## 4. 빈 상태 & 에러 상태

### 4-1. 대시보드 — Queue 테이블 빈 상태 (Empty State)

> **조건**: 생성된 Job이 하나도 없을 때

Queue 테이블 영역 정중앙에 세로 스택으로 배치합니다.

```
[아이콘: FilmSlate, 72px, #8b5cf6 @ opacity 30%]

아직 생성된 북트레일러가 없습니다.
왼쪽 패널에서 ISBN을 입력하거나
주간 큐레이션을 예약해 보세요.

[버튼: "지금 생성 시작하기" — 아웃라인 스타일, 클릭 시 좌측 폼으로 포커스 이동]
```

스타일: 아이콘 → 제목(16px Semi Bold) → 설명(14px Regular, opacity 60%) → 버튼 순 세로 정렬, gap `space-4`.

---

### 4-2. 대시보드 — API 조회 실패 인라인 배너 (Error Banner)

> **조건**: 정보나루 API 호출 실패 또는 서버 연결 오류

테이블 전체를 막는 오버레이 대신, **테이블 상단에 인라인 배너**로 표시합니다.

```
┌─────────────────────────────────────────────────────────────┐
│ ⚠  데이터를 불러오지 못했습니다. 잠시 후 다시 시도해 주세요.   재시도 →  │
└─────────────────────────────────────────────────────────────┘
```

- 배경: `rgba(239, 68, 68, 0.10)`
- 좌측 보더: `#ef4444`, 4px solid
- `WarningCircle` 아이콘 (레드, 20px) + 텍스트 + "재시도" 텍스트 버튼 (레드, 언더라인)
- border-radius: `10px`

---

### 4-3. 대시보드 — Job 실패 툴팁 (Error Tooltip)

> **조건**: 상태 배지가 Failed인 행에 마우스 오버 시

```
┌──────────────────────────────┐
│  TTS 음성합성 단계에서 오류 발생  │
│  Error: CONNECTION_TIMEOUT   │
└──────────────────────────────┘
```

- 배경: `rgba(17, 24, 39, 0.95)`
- 폰트: 12px Regular, 흰색
- 최대 폭: 240px / border-radius: `8px`
- 위치: 배지 상단 중앙 기준 위로 `8px` 오프셋

---

### 4-4. 모바일 — 주변 소장 도서관 없음 (No Libraries)

> **조건**: 반경 내 해당 ISBN 소장 도서관이 0곳일 때

```
[아이콘: BookBookmark, 56px, #0f766e]

아쉽게도 근처에 소장 도서관이 없어요.
검색 범위를 넓혀 확인해 보세요.

[버튼: "전국 소장 도서관 보기" — 민트 아웃라인, 정보나루 ISBN 검색 딥링크]
```

스타일: 카드 영역 중앙 정렬, 민트 계열 컬러 적용.

---

### 4-5. 모바일 — 위치 권한 영구 거부 (Permission Denied)

> **조건**: 브라우저 설정에서 위치 권한이 영구 차단된 경우

```
[아이콘: GlobeHemisphereWest, 56px, #9ca3af]

위치 접근이 차단되어 있어요.
브라우저 설정에서 위치 권한을 허용하시면
가장 가까운 도서관을 안내해 드릴 수 있어요.
```

이후 하단에 **IP 기반 기본 지역 도서관 목록 Fallback 카드**를 그대로 표시합니다.
Fallback 카드 상단에 소형 안내 뱃지 추가: `"📍 기본 지역 기준 안내"` (웜 그레이 배경)

---

### 4-6. 모바일 — 도서 정보 로드 실패 (Metadata Error)

> **조건**: LOD/정보나루에서 도서 메타데이터를 가져오지 못했을 때

- 도서 제목 자리: `"도서 정보를 찾을 수 없습니다"` 그레이 텍스트로 교체
- 저자 자리: 빈 줄 또는 `"—"` 표기
- 헤더 카드 배경 색상: 딥 틸(`#0f766e`) → 웜 그레이(`#6b7280`)로 fallback
- 도서관 목록 카드는 정상 표시 유지 (메타데이터와 독립적)

## 5. 인터랙션 플로우

### 5-1. 수동 생성 요청 버튼 클릭 플로우

```
[초기 상태]
"북트레일러 생성 큐 예약" 버튼 — 활성, 네온 그라데이션

  ↓ 클릭

[로딩 상태]  (클릭 즉시 ~ API 응답까지)
버튼: 비활성화 + 내부 SpinnerGap 아이콘 회전 + "요청 중..." 텍스트
입력 폼: 전체 비활성화 처리 (opacity 50%)

  ↓ 성공 응답

[성공 피드백]  (1,500ms 유지 후 자동 초기 상태 복귀)
버튼: 민트 그린 배경 + "✓ 큐에 추가됨"
입력 폼: 자동 초기화 (값 클리어)
Queue 테이블: 최상단에 신규 Job 행 슬라이드-인 (translateY -8px → 0, 250ms ease-out)
토스트 알림 (우측 상단): "[도서 제목] 북트레일러가 생성 예약되었습니다" (3초 후 자동 소멸)

  ↓ 실패 응답

[실패 피드백]  (1,500ms 유지 후 자동 초기 상태 복귀)
버튼: 레드 계열 배경 + "✗ 요청 실패"
인풋 하단: 인라인 에러 메시지 표시 (예: "유효하지 않은 ISBN입니다")
입력값: 유지 (사용자가 수정할 수 있도록)
```

---

### 5-2. Queue 테이블 — Job 상태 전환 애니메이션

각 행의 상태 배지는 **5초 간격 폴링**으로 백엔드에서 업데이트됩니다.

```
queued (회색 아웃라인)
  ──→ cross-fade 200ms
running (퍼플 소프트 네온 + pulse 애니메이션)
  │
  └─ "현재 단계" 텍스트 실시간 교체 (fade 150ms):
     "서지 조회 중..." → "대본 생성 중..." → "TTS 합성 중..."
     → "자막 정렬 중..." → "비디오 렌더링 중..."
  │
  ├──→ cross-fade 200ms
done (민트 그린 배지)
  │   + 해당 행 전체: 은은한 민트 하이라이트 flash 1회 (opacity 0→0.08→0, 600ms)
  │   + 액션 버튼 3종 등장 (fade-in 200ms): 미리보기 / MP4 저장 / QR 확인
  │
  └──→ cross-fade 200ms
failed (네온 레드 배지)
     + WarningCircle 아이콘 추가
     + 해당 행: 마우스 오버 시 에러 툴팁 표시
```

### 5-3. 비디오 미리보기 모달 열기/닫기

```
[미리보기 버튼 클릭]
→ 배경 블러 오버레이 fade-in (200ms, rgba(0,0,0,0.85) + blur 8px)
→ 모달: scale(0.95 → 1.0) + fade-in (250ms, ease-out)
→ 비디오 자동 재생 시작

[닫기 — X 버튼 클릭 또는 오버레이 영역 클릭]
→ 비디오 즉시 정지 (음소거 처리 후 정지)
→ 모달: scale(1.0 → 0.95) + fade-out (200ms)
→ 배경 오버레이: fade-out (150ms)
```

모달 내부 구성:
- 상단 우측: X 닫기 버튼 (흰색 아웃라인 원형, 36px)
- 중앙: 9:16 비율 비디오 플레이어 (최대 높이 80vh 제한)
- 하단: 도서 제목 + "MP4 저장" 버튼 (모달 하단 고정)

### 5-4. 모바일 — GPS 획득 및 카드 로드 플로우

```
[페이지 최초 진입]
→ 0.5초 후 브라우저 위치 권한 팝업 표시 (OS 기본 UI)
→ 도서관 카드 3개 영역: 즉시 스켈레톤 로딩 표시 (shimmer 애니메이션)

  [권한 허용]
  → GPS 배지: 옐로우 "탐색 중..." + SpinnerGap 회전
  → (위치 수신 완료)
  → GPS 배지: 옐로우 → 민트 그린 "내 위치 수신 완료" cross-fade (300ms)
  → 스켈레톤 → 실제 카드 데이터 순차 fade-in:
     1번 카드 → 100ms → 2번 카드 → 100ms → 3번 카드 (Staggered)

  [권한 거부]
  → GPS 배지: 웜 그레이 "위치 권한이 필요합니다" + GlobeHemisphereWest 아이콘
  → Fallback: IP 기반 기본 지역 도서관 목록 로드
  → 스켈레톤 → Fallback 카드 동일한 순차 fade-in
```

## 6. 컴포넌트 상태 정의

### 6-1. 버튼 (Primary — 네온 그라데이션)

| 상태 | 배경 | 테두리 | 텍스트 | Glow 효과 |
|---|---|---|---|---|
| Default | 퍼플 → 핑크 그라데이션 | 없음 | 흰색 Bold | Drop Shadow, Blur 15px, 30% |
| Hover | 밝기 +10% | 없음 | 흰색 | Drop Shadow, Blur 20px, 50% |
| Pressed | 밝기 -5%, scale 0.98 | 없음 | 흰색 | Glow 감소 |
| Loading | 그라데이션 opacity 50% | 없음 | 흰색 + SpinnerGap | 없음 |
| Success | `#10b981` 단색 | 없음 | 흰색 | 없음 |
| Failed | `#ef4444` 단색 | 없음 | 흰색 | 없음 |
| Disabled | `rgba(255,255,255,0.08)` | `rgba(255,255,255,0.10)` | `rgba(255,255,255,0.30)` | 없음 |

### 6-2. 인풋 필드 (텍스트 입력)

| 상태 | 배경 | 테두리 | 추가 요소 |
|---|---|---|---|
| Default | `rgba(255,255,255,0.04)` | `rgba(255,255,255,0.10)` 1px | Placeholder 텍스트 opacity 40% |
| Focus | `rgba(255,255,255,0.07)` | `#8b5cf6` 1.5px | 퍼플 외곽 포커스 링 (4px glow) |
| Filled | `rgba(255,255,255,0.06)` | `rgba(255,255,255,0.15)` 1px | 텍스트 흰색 |
| Error | `rgba(239,68,68,0.08)` | `#ef4444` 1.5px | 하단 에러 텍스트 (12px, 레드) + XCircle 아이콘 |
| Disabled | `rgba(255,255,255,0.02)` | `rgba(255,255,255,0.05)` 1px | 텍스트 opacity 40% |

### 6-3. Job 상태 배지

| 상태 | 배경 | 테두리 | 텍스트 | 애니메이션 |
|---|---|---|---|---|
| Queued (대기) | `rgba(156,163,175,0.15)` | `rgba(156,163,175,0.40)` | 그레이 | 없음 |

### 6-4. 도서관 카드 (모바일)

| 상태 | 설명 |
|---|---|
| Skeleton | 카드 형태 유지, 내부 전체 shimmer 그라데이션 (좌→우 sweep, 1.5s loop) |
| Default | 흰색 배경, `#e5e7eb` 1px 보더, 정상 데이터 표시 |
